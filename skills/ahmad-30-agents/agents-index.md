# The 30 Agents — Master Index

Routing table for the 30 named agents in *30 Agents Every AI Engineer Must Build* (Imran Ahmad, PhD, Packt 2026).

**Use this when you have an agent name and need everything else** — e.g. "Verification and Validation Agent" → Ch 8 → `chapters/ch08-data-reasoning.md` → `chapter08/` → the no-key simulation notebook. Go the other way too: given a chapter, see which agents it delivers.

**Naming authority**: the **book** is canonical for agent names; the **repo** is canonical for file paths. They disagree in several places — see [Book vs repo discrepancies](#book-vs-repo-discrepancies) at the end. Names below are printed as the book's section headings render them (the book lowercases "agent" in most headings and uses plural forms in Chs 6, 9, and 11).

**Page citations** follow the skill convention `(Ch N, p. ~NNN)`, where `NNN` is the **EPUB page-anchor number**, which runs **+31 ahead of the printed page** (verified against running headers: printed "447" sits at `id="page_478"`). Anchors are not converted.

## Book vs repo discrepancies

Every claim below was verified against the EPUB `toc.ncx`, the chapter body text, the repo README, and the repo notebooks. **Root cause for D1–D3**: the repo README's agent lists were written from the book's **preface blurbs** ("What this book covers", `index_split_030.html` / `index_split_031.html`), not from the chapters as delivered. Where preface and chapter disagree, the chapter is authoritative.

### D1 — CONFIRMED: "The Recommendation Agent" does not exist in the book

The repo README lists it twice: as agent **#18** in the numbered 30, and in the Chapter 10 row of the chapter table.

- The book's TOC for Ch 10 contains exactly two agent sections: *The Conversational agent* and *The Content Creation agent*.
- The string "recommendation agent" appears **once in the entire book**, in the Ch 10 preface blurb: "…and recommendation agents with hybrid recommender architectures."
- Ch 10's body contains one stray forward-reference — it says the chapter "foreshadows the recommendation and content generation agents explored later in this chapter" `(Ch 10, p. ~314)` — but no such section is ever delivered.
- `chapter10/ch10_conversational_and_content_creation_agents.ipynb` has **zero** matches for `recommendation agent`, `hybrid recommender`, or `RecommendationAgent`. The repo's own `chapter10/README.md` does not list it either.

**Treatment**: excluded from the 30. Do not cite a Recommendation Agent as a book agent.

### D2 — CONFIRMED: #14 is "Compliance-Driven agents", not "The Security-Hardened Agent"

- The delivered Ch 9 section heading is **Compliance-Driven agents** `(Ch 9, p. ~286)`, with subsections on static compliance validation, data flow analysis, audit trail generation, and a PCI DSS CI/CD implementation.
- "Security-hardened" appears **once in the entire book** — in the Ch 9 preface blurb ("security-hardened agent patterns for prompt injection defense"). It is not a section, and prompt-injection defense is covered in Chs 3–4, not in this Ch 9 section.

**Treatment**: use *Compliance-Driven agents*. Note that SKILL.md's Chapter Index still summarizes ch09 as "security hardening" — that phrasing traces to the same preface blurb.

### D3 — CONFIRMED: "Domain-Transforming Integration" is missing from the repo's numbered 30

- The book's TOC lists **The Domain-Transforming Integration agent** as a full Ch 16 section `(Ch 16, p. ~504)`, with its own subsections (coupled heterogeneous dynamical systems, domain knowledge graph, influence propagation, and an explicit "Contrast with the Embodied Intelligence agent").
- The repo README's **chapter table** (Chapter 16 row) does list it.
- The repo README's **numbered list of 30** does not: entry #30 is Embodied Intelligence, and the list ends there.

**Net arithmetic**: the repo's numbered list drops Domain-Transforming Integration and adds the non-existent Recommendation Agent, so it still sums to 30 while being wrong at both ends. Counting the book's delivered sections yields exactly 30 with no slack: 3+3+3+3+3+2+3+2+2+2+2+2 across Chs 5–16.

### D4 — CONFIRMED: errata, Ch 5 code path

Repo `ERRATA.md` (ISBN 978-1-80610-901-2, logged 2026-04-08): at Ch 5, **printed page 118**, the book prints

```
cd 30-Agents-Every-AI-Engineer-Must-Build/"Chapter 05"
```

The real folder is lowercase, unpadded-style `chapter05`. Every repo folder follows `chapterNN` with no spaces and no capital C. Running the printed command fails with "No such file or directory". Note this errata cites the **printed** page 118 (repo convention), not an EPUB anchor.

### D5 — NEW: singular/plural and capitalization drift in agent names

The repo README title-cases every agent and forces the singular ("The Knowledge Retrieval Agent"). The book lowercases "agent" in most headings and uses the **plural** for all of Ch 6, Ch 9's first two, and all of Ch 11 — e.g. *Knowledge Retrieval agents*, *Code-Generation agents*, *Vision-Language agents*. Chs 7's second and third entries are not called "agents" at all: *the chain-of-agents orchestrator* and *the agentic workflow system*. Cosmetic, but it means exact-string lookups against the book will miss if built from the repo's names.

### D6 — NEW: Ch 12 is the only chapter split across two notebooks

Every other chapter ships one notebook family per chapter. Ch 12 ships two, one per agent: `ch12_01_ethical_reasoning_agent*` and `ch12_02_explainable_agent*`. Additionally, `ch12_02_explainable_agent` ships **only** the base and `__RUN_NO_KEY_SIMULATION` variants — the OpenAI, Claude, Gemini, and Ollama provider notebooks that every other chapter carries are absent. Plan around this when comparing providers across chapters.

## Verification method

- Agent roster and section order: EPUB `toc.ncx` navPoint labels, cross-checked against chapter body headings.
- Page anchors: nearest preceding `id="page_N"` before each section heading. The EPUB is a PDF-reflow conversion, so in Chs 8, 13, 15, and 16 the section heading is merged into the opening body paragraph rather than standing alone; those were resolved by locating the merged heading text. Index markers of the form `idx_XXXXXXXX` are injected mid-word throughout and must be stripped before matching.
- Anchor-to-print offset: `+31`, confirmed against running-header paragraphs at multiple points (printed 447 → `page_478`, printed 465 → `page_496`, printed 473 → `page_504`).
- Notebook filenames: enumerated directly from each `chapterNN/` folder. No filename in this index was inferred from a pattern.
